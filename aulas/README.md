# Aulas

Cada aula é um arquivo desta pasta, preparado pelo Claude com base nos temas da trilha ([TRILHA_JAVA_JUNIOR.md](../TRILHA_JAVA_JUNIOR.md)).
Seus códigos ficam em `exercicios/aula-XX/`.

## Como pedir

| Quando | O que escrever |
|---|---|
| Começo do dia | **"Me passa a aula de hoje"** |
| Travou em algo | Cole o erro ou o código e pergunte |
| Terminou os exercícios | **"Corrige a aula XX"** |
| Terminou a fase | **"Terminei a Fase X, valida e me passa os posts"** |

## Plano da Fase 1: Fundamentos Java (15 dias)

### Módulo 01 · Criando a sua primeira aplicação
- [ ] Aula 01: ambiente, primeiro programa, variáveis, tipos e operadores
- [ ] Aula 02: condicionais (`if`/`else`, `switch`) e entrada de dados com `Scanner`
- [ ] Aula 03: laços (`while`, `for`); mini projeto: menu de caixa eletrônico no terminal

### Módulo 02 · Orientação a Objetos
- [ ] Aula 04: classes, objetos, atributos e métodos
- [ ] Aula 05: encapsulamento, construtores, getters/setters e pacotes
- [ ] Aula 06: herança, sobrescrita e `super`
- [ ] Aula 07: interfaces e polimorfismo; mini projeto

### Módulo 03 · Listas e coleções
- [ ] Aula 08: `ArrayList`, for-each e `record`
- [ ] Aula 09: ordenação (`Comparable`, `Comparator`), `equals` e `hashCode`
- [ ] Aula 10: `Set` e `Map`; mini projeto

### Módulo 04 · Consumindo API, gravando arquivos e lidando com erros
- [ ] Aula 11: exceções (`try`/`catch`/`finally`, `throw`)
- [ ] Aula 12: consumindo uma API com `HttpClient` (ViaCEP)
- [ ] Aula 13: convertendo JSON em objetos Java
- [ ] Aula 14: gravando arquivos; mini projeto: buscador de CEP que salva os resultados
- [ ] Aula 15: revisão, validação da Fase 1 e posts
